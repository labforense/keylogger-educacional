Curso de Simulação de Segurança Ofensiva - Tutorial Didático sobre Keyloggers em Python

## 📖 O que é este Projeto?

Este é um **projeto educacional controlado** que ensina como funcionam keyloggers, através de código, análise e defesa. Desenvolvido para fins de aprendizado em ambientes de simulação de segurança.

### Tópicos Cobertos

- ✅ Funcionamento interno de keyloggers
- ✅ Captura de eventos do teclado em Python
- ✅ Logging e armazenamento de dados
- ✅ Tratamento de exceções
- ✅ Análise de segurança e ameaças
- ✅ Técnicas de defesa e proteção
- ✅ Considerações éticas e legais

## 🚀 Quick Start

### Pré-requisitos

- Python 3.8 ou superior
- pip (gerenciador de pacotes)

### Instalação

```bash
# Clone o repositório
git clone https://github.com/SEU_USER/keylogger-educacional.git
cd keylogger-educacional

# Instale dependências
pip install -r requirements.txt
```

### Uso

```bash
# Execute o keylogger
python keylogger.py

# Pressione ESC para parar
```

Dados serão salvos em `keys.log`

## 🛡️ Proteção e Defesa

Como se proteger contra keyloggers:

1. **Antivírus/Antimalware**
   - Windows Defender
   - Malwarebytes
   - ESET

2. **Boas Práticas**
   - Manter Windows atualizado
   - Usar senhas fortes
   - Ativar 2FA
   - Verificar downloads

3. **Monitoramento**
   - Verificar processos estranhos
   - Monitorar conexões de rede
   - Verificar arquivos suspeitos
